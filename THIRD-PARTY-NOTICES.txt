Contents
  1. RetroPixels programs (RetroPixels, RetroPixels Native, the Android app)
  2. PixelU (PixelU\PixelU.exe, Wii U engine)
  3. PixelU-Wii (PixelU\wii\PixelU-Wii.exe, GameCube and Wii engine)

  5. MAME (MAME\, arcade engine; a separate program)
  6. Programs RetroPixels can download or use but does not include

1. RetroPixels programs
=============================================================================

RetroPixels.exe, RetroPixels-Native.exe, the Linux "RetroPixels" program and
the Android app's engine (librpengine.so) are written in Go. The Android
app's own code uses only Android's built-in classes (no libraries are
packaged into the app; JUnit is used for tests only).

4. RetroPixels' Model 3 engine (Supermodel folder)
=============================================================================

supermodel.exe (Linux: supermodel; Android: libsupermodel.so) plays Sega
Model 3 games. It is RetroPixels' own software (LICENSE.txt): it began as a
copy of Supermodel (https://github.com/trzy/Supermodel, The Supermodel
Team, GNU GPL version 3 or later), and every part of that has since been
replaced by code, build files, data and pictures written for RetroPixels
(docs/supermodel-original.md), including its 68000 processor (RetroPixels'
own, from its Go 68000 in cores/m68k), its Windows resources, its game list
(Config/Games.xml) and its crosshair pictures. No Supermodel code or files
are in it or shipped with it. Builds of it published before this change
were distributed under the GPL with their source, and stay available under
the GPL to those who received them.

5. MAME
=============================================================================

The MAME folder holds the MAME team's official MAME release, unchanged
(https://www.mamedev.org/). MAME is a separate program that RetroPixels
starts; it is Copyright Nicola Salmoria and the MAME team and is
distributed as a whole under the GNU General Public License, version 2 or
later, with parts under BSD-3-Clause and other licences (its COPYING file
and docs\legal folder). MAME's source code for the version included is
published with each RetroPixels release (MAME-<version>-source.tar.gz) and
at https://github.com/mamedev/mame.


=============================================================================
6. Programs RetroPixels can download or use but does not include
=============================================================================

- FFmpeg (for recordings): not included. When you ask for it, RetroPixels
  downloads an FFmpeg build from https://github.com/BtbN/FFmpeg-Builds
  (GNU GPL) and saves that build's LICENSE.txt next to it. FFmpeg runs as a
  separate program.
- Dolphin: RetroPixels can start a Dolphin you installed yourself; it is
  not included.
