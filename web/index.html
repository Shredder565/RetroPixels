Nintendo 64, Sega & Atari

Nintendo 64A = A  ·  X = B  ·  LT = Z  ·  LB/RB = L/R  ·  left stick = analog stick  ·  right stick = C buttons  ·  Menu = Start
Keyboard: arrows = stick · X / Z = A / B · A = Z · Q / W = L / R · I J K L = C buttons · T F G H = D-pad · Enter = Start
GenesisX A B = A B C  ·  LB Y RB = X Y Z  ·  View = Mode
Atari 2600A = Fire  ·  Menu = Reset switch  ·  View = Select switch  ·  LB/RB = difficulty switches  ·  Y = Color/B&W  ·  paddle games: left stick
Atari 7800A / B = fire buttons  ·  Menu = Pause  ·  View = Select  ·  Y = Reset

Save state & recording shortcuts

Click right stick R3Save to current slotF2
Click left stick L3Load current slotF4
Right stick ← / →Change slotF3
Right stick ↓ (hold 1 sec)Start / stop recordingF9
On Nintendo 64 the right stick is the C buttons, so use View + D-pad ← / → to change slot and View + D-pad ↓ to start/stop recording.

The layout follows button position, like the original pads: Xbox A (bottom) is the bottom Nintendo button, Xbox B (right) is the right one. Remap anytime: 🎮 Controls in the game's bar.

Recordings

RetroPixels records your GameCube and Wii games as .mp4 videos — just the game picture (black bars cropped off) and just the game's sound. Classic-console games are recorded with the ● Record button above the game instead (or by holding the right stick down), and save to your Downloads folder.

GameCube and Wii games play in Dolphin through the RetroPixels desktop app (RetroPixels.exe).

Dolphin is open. Settings changes are paused until you close it.
