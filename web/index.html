Recordings

RetroPixels records your GameCube and Wii games as .mp4 videos — just the game picture (black bars cropped off) and just the game's sound. Classic-console games are recorded with the ● Record button above the game instead (or by holding the right stick down), and save to your recordings folder (Videos\RetroPixels unless you choose another).

PixelU

GameCube and Wii games play in PixelU (Wii/GameCube engine based on Dolphin, GPL), RetroPixels' emulator. Dolphin is the open-source GameCube and Wii emulator (GPL-2.0+). Your Dolphin controller settings, memory cards and Wii saves are copied over the first time a game starts (nothing is overwritten).

Use PixelU itself for memory cards, cheats and per-game settings.

PixelU

PixelU is RetroPixels' Wii U emulator, based on Cemu (the open-source Wii U emulator, MPL-2.0). Its settings, saves and shader caches stay in its own folder.

Use PixelU itself to set up controllers (Options → Input settings), graphics, graphic packs and online play.

Arcade games play in MAME, any version of it, through the RetroPixels desktop app (RetroPixels.exe).

Arcade games in MAME

Play any arcade game in any version of MAME. MAME comes with RetroPixels (the MAME team's official release, unchanged), and you can add other versions. A ROM set has to match the MAME version it was made for, so each game can use its own version: pick it next to the game. RetroPixels' own arcade emulators stay in the Classic consoles tab.

Download a MAME version

Any official Windows release from the MAME team (github.com/mamedev/mame). Each version gets its own folder next to RetroPixels, so they don't replace each other.

Playing

Click the game to give it the keyboard. MAME's keys: 5 coin, 1 start, arrows to move, Ctrl Alt Space buttons, Tab MAME's menu, P pause, Shift+F7 / F7 save / load state, Esc quit. Xbox controllers work too. Each MAME keeps its own settings and saves in its folder.

Playing

Xbox controller: left stick flies (the arcade's flight yoke), A or RT fires, B or RB is the yoke's thumb button, Start starts, Back (View) adds a coin, Back + Start leaves the game.

Mouse, at the same time as the controller: point to aim, left button fires, right button is the thumb button, middle button is the second trigger. Whichever you moved last steers.

Keyboard: 5 coin, 1 start, arrow keys fly, Ctrl fire, Alt thumb button, 9 service, F2 test menu, F5 / F7 save / load state, Alt+P pause, Esc leaves.

The game's start-up checks are skipped: it opens on its title, ready for coins and Start.

Supermodel

Supermodel here is RetroPixels' own Sega Model 3 engine, in the Supermodel folder. It began as a copy of the open-source Supermodel emulator (thanks to the Supermodel team) and has been rewritten for RetroPixels. Your settings, high scores (NVRAM) and save states stay in RetroPixels' own folder.

RPCS3

RPCS3 is the open-source PlayStation 3 emulator (GPL-2.0, rpcs3.net). RetroPixels starts the RPCS3 you have; it doesn't come with RetroPixels. The PS3 system software, your games and their licences are your own files: RetroPixels never downloads them.

Archipelago

  1. Open the Archipelago Launcher and start the BizHawk Client. It finds RetroPixels by itself — you don't need BizHawk or its Lua script.
  2. In the client, connect to the multiworld server (for example /connect archipelago.gg:38281) and enter your player name if it asks.
  3. Keep playing here. Items you find are sent, and items from others arrive in the game.

RetroPixels answers the client only on this computer (127.0.0.1). Its save files and save states for this game are kept apart from the same game without the patch.

Machine settings (DIP switches)

These are the switches on the game's circuit board. Most games read them when they start, so press ↺ Restart after changing one. They're kept for this game.

Save states

Save states are kept in this browser, separately for each game. Controller: click the right stick to save, click the left stick to load, flick the right stick left/right to change slot. In-game battery saves still work as normal.
