Features

One window for every system

Drop a game on the window. Zipped games open directly and the system is detected for you.

Written from scratch

Every CPU, graphics chip, sound chip and arcade board of the built-in systems is RetroPixels' own code, except the Sega Model 3 sound chips, which follow Supermodel's (GPL-3.0). Works offline, no BIOS files needed.

Xbox controllers, up to four players

Plug in and play, remap any button, and pick which player you are in 4-player games.

Records just the game

Every game is recorded automatically, on every system. Videos contain only the game picture and sound. No borders, cursor, black bars or other windows.

Saves handled for you

Battery saves are kept automatically. Save states with undo, and imports from other emulators.

Wii U, GameCube and Wii

PixelU, RetroPixels' own Wii U and GameCube / Wii engines, come in the download and play inside the same window. Use your own game dumps and your own console's keys.

Star Wars Trilogy Arcade

Sega Model 3 on RetroPixels' own emulator, built in: the 3D board, sound board and MPEG music, with the Xbox stick as the flight yoke (flight stick feel) or the mouse. Nothing else to install.

MAME built in, any version

The download comes with the MAME team's official release of MAME, unchanged. Add as many other MAME versions as you like, and RetroPixels checks which one plays each game.

Getting started

  1. Download RetroPixels-x.y.z.zip (or RetroPixels-Native-x.y.z.zip) from the latest release and unzip it.
  2. Run RetroPixels.exe (or RetroPixels-Native.exe). Keep the PixelU and MAME folders next to it.
  3. Drop a game you own onto the window.
NoteThe program isn't code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway.
