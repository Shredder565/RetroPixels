# Third-party material in PixelU

Code and data in `pixelu/` that RetroPixels did not write. Each item keeps its
own licence. `tools/pixelu-original.py` counts the source files below as
third-party (its `THIRD_PARTY` tuple), and `docs/pixelu-original.md` keeps
the line counts.

|---|---|---|
| Icons8 icons (game list, settings, hotkeys, input and debugger pictures) | `src/resource/icons8*`, `src/resource/input/icons8*`, `src/resource/debugger/icons8*`, and the copies built into the program in `src/resource/embedded/` (`X_*.xpm`, `PNG_*.hpng`, `DEBUGGER_*.hpng`, `INPUT_*.hpng`, `icons8-*.hpng`) | Icons8 licence ([icons8.com/license](https://icons8.com/license)). | Lato Medium (fallback system font, zlib-compressed) | `src/resource/CafeDefaultFont.cpp` | SIL Open Font License 1.1 |
| "More Perfect DOS VGA" bitmap font (OSScreen text) | `src/Cafe/OS/libs/coreinit/coreinit_OSScreen_font.h` | freeware font; the file carries no licence text |

made from `web/icon-512.png`.

It is a separate program with its own notices.
